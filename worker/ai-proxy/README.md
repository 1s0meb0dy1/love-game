# Проксі ШІ-підказок ASK ME (Cloudflare Workers + Gemini)

Навіщо: безкоштовний Pollinations тепер дає 1 відповідь на 30 с з однієї IP-адреси, тому «Ситуація» й «Порада» часто ламалися.
Проксі тримає ключ Gemini на сервері (у браузер він не потрапляє), віддає відповідь потоком і сам перемикається між моделями.

Як працює запит: сайт надсилає лише тип підказки, мову, текст питання, тему й кількість гравців (без імен).
Воркер сам складає промпт (`src/ai/prompts.js`), тож використати його як безкоштовний чат-бот для інших задач не вийде.
Порядок: моделі з `GEMINI_MODELS` по черзі (якщо модель мовчить 9 с або повертає помилку — наступна) → Pollinations
(якщо задано `POLLINATIONS_KEY`) → одна з останніх відповідей на це ж питання з кешу Cloudflare. Вміст запитів не логуються.
Обмеження: 20 запитів за хвилину з однієї IP (`[[ratelimits]]` у `wrangler.toml`), запити лише з сайту гри (`ALLOWED_ORIGINS`).

## Розгортання (один раз, ~10 хвилин)
1. Ключ Gemini: https://aistudio.google.com/apikey → «Create API key». Безкоштовного рівня вистачає на старт.
2. Акаунт Cloudflare (безкоштовний): https://dash.cloudflare.com/sign-up.
3. У терміналі в папці репозиторію:
   ```
   cd worker/ai-proxy
   npx wrangler@4 login                       # відкриє браузер, підтвердьте доступ
   npx wrangler@4 secret put GEMINI_API_KEY   # вставте ключ із кроку 1 (у чат і в код його не вставляйте)
   npx wrangler@4 deploy                      # надрукує адресу на кшталт https://askme-ai.<ваш-субдомен>.workers.dev
   ```
4. Впишіть цю адресу в `AI_PROXY_URL` у `src/ai/client.js` і опублікуйте сайт.

## Обслуговування
- Змінити моделі: `GEMINI_MODELS` у `wrangler.toml`, потім `npx wrangler@4 deploy`.
- Запасний платний шлях: `npx wrangler@4 secret put POLLINATIONS_KEY`.
- Новий домен сайту: додайте його в `ALLOWED_ORIGINS` через кому.
- Безкоштовний рівень Gemini: Google може використовувати запити для покращення своїх моделей (це вказано в політиці
  конфіденційності гри). Щоб це вимкнути, увімкніть оплату в Google AI Studio (платний рівень).
- Перевірка: `npm test` у корені запускає `tests/unit/ai-worker.test.js` (CORS, перемикання моделей, кеш).
