## Границы доказательства

Регрессионные проверки запускают текущий React-код в jsdom с локальной сетью-моделью. Unit-проверки координаторов моделируют реальную семантику ETag/If-Match и явно требуют PUT: условный PATCH в RTDB не поддерживается. Это не заменяет испытание на реальном движке Rules и в мобильных браузерах.

Набор `npm run test:rules` подготовлен для `demo-love-game`. Запуск остановился при загрузке официального `firebase-database-emulator-v4.11.2.jar` с `storage.googleapis.com`: домен не разрешён текущей сетевой политикой. JSON и импорты теста проверены; успешной компиляции и выполнения правил эмулятором пока нет. Поэтому серверные пункты не объявляются закрытыми и Rules не публикуются.

MFA владельца, App Check, ограничения API key, глобальные квоты создания сессий и очистка старых записей требуют доступа к проекту и отдельной проверки. Индексные проверки Rules ограничивают массивы, но не являются глобальной квотой произвольных новых узлов.

Подробные команды проверки, миграция исторической аналитики и согласованный выпуск описаны в [security-rollout.md](security-rollout.md).
