# ASK ME · Strategy Atlas 2026

Самодостаточный документ-стратегия (HTML, шрифты встроены, интернет не нужен) и его PDF-версия.

| Файл | Что это |
|---|---|
| `ask-me-strategy-atlas.html` | Готовый документ: 25 глав (в т. ч. гл. 23 «Рабочие материалы»: бэклог на 240 ч, события аналитики, тексты сторов UK/EN, календарь, дерево решений, эскизы), поиск ⌘K / Ctrl K, тёмная и светлая тема, калькулятор, обозреватель 278 названий, банк 497 карточек (RU/EN/UK) с экспортом |
| `ask-me-strategy-atlas.pdf` | Печатная версия (A4, светлая тема, 157 страниц) |
| `build.mjs` | Сборщик: `node docs/strategy/build.mjs` → пересоздаёт HTML |
| `render.mjs`, `template/` | Рендер блоков, стили, клиентский JS |
| `content/` | Главы (`c00…c24.mjs`; `c24` стоит в оглавлении перед `c23`), карточки (`bank.mjs`), украинский перевод карточек (`bank-uk.mjs`, порядок строк = порядок карточек), пояснения к названиям (`names.mjs`) |
| `data/` | Результаты проверки 240 названий (RDAP + Google Play), 462 вариантов `.com`, данные прошлого файла |

## Как обновить

1. Правьте текст в `content/cNN.mjs` (блоки: `p`, `table`, `cards`, `diff`, `hbar`, `palette` и др. — см. `render.mjs`).
2. `node docs/strategy/build.mjs` — сборка; она сама проверяет контраст токенов обеих тем (не ниже 4,5:1) и предупреждает о названиях без пояснений.
3. PDF: открыть HTML, «⬇ PDF / печать» (или Playwright `page.pdf` с `emulateMedia('print')`).

Метки уверенности в тексте: `::fact::`, `::src::`, `::model::`, `::know::`, `::hyp::`, `::unk::` (расшифровка — в главе 00).

Документ не меняет приложение: версию в подвале (`npm run bump`) поднимать не нужно.
