# ASK ME — памятка для работы с кодом

Подробности — в `README.md` (команды, режимы, правила) и `docs/design-system/page.html` (дизайн-система «Heat»).

- **Версия приложения.** Любое изменение приложения поднимает версию в подвале на шаг: `npm run bump` (а → б → в …); хук `.githooks/pre-commit` делает это сам, если включён `git config core.hooksPath .githooks`. Числа «0», «1» и «29» в `0.1.29а` меняются только по просьбе владельца. Файл: `src/content/version.js`.
- **Тексты.** Интерфейс пишется по-русски через `tr()` / `tf()`; у каждой новой строки должен быть перевод в `src/i18n.js` (UK) и `src/i18n-en.js` (EN) — это проверяет `tests/unit/i18n.test.js`.
- **Компьютер.** Всё, что есть только на компьютере, живёт в `@media (min-width: 1024px)` или за `useIsDesktop()`; на телефон не переносится и ход игры не меняет.
- **Дизайн-система.** Новый компонент или токен — в `src/styles.css` (правила пишутся селектором `:root .класс`) и в `docs/design-system/page.html`.
- **Проверка перед загрузкой.** `npm run verify` (тесты, сборка, вес). UI-тесты читают `src/` при старте — не правьте код, пока они идут.
